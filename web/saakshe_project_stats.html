01What saakshe actually is

A company is modelled as five agent systems sharing one memory, one event stream, and one conscience. The conceit: staff are agents, and the founder talks to the company instead of operating it.

manas

the mind · knows

Versioned, source-cited memory. Imbibes documents, the web, founder voice and "the world's pulse", and refuses to commit a memory that isn't grounded. It never acts.

arivu

the judgment · decides

A deliberation chamber. Five advisors argue a decision to convergence; a chair synthesises a verdict; a prosecutor tries to defeat it; then it halts for the founder.

kalai

the studio · makes

Brand-fidelity creative studio. Climbs to a quality threshold and passes a fail-closed compliance gate. Holds no channel keys — it never publishes.

kural

the mouth · engages

The company's only mouth. Researches the audience and timing, carries kalai's cleared words untouched (it authors nothing), and halts at the publish tap before anything reaches the world.

witness

the founder's seat · sees

The thing you talk to. Answers only from the live stream via telemetry tools, refuses what it can't see, and speaks (text + voice). It initiates nothing.

+ the flywheel

orchestrator · binds

A resumable state machine that drives manas → arivu → kalai → kural → manas with two founder gates. One ordered event stream feeds every screen.

Built for two hackathons in parallel (Google AI Agents + Rapid Agent) and unified into a single backend on 2026-06-08: one common substrate, four real-ADK quadrants, the witness, the orchestrator, and one FastAPI service — backend green (139 tests).

06The witness — what you talk to

The founder's seat. It has no static knowledge — every answer is a call to a telemetry tool reading the one event stream. If you ask something it can't see, it refuses rather than invent. Same contract in text and in voice.

5 telemetry tools

tools-over-telemetry
  • who's acting now — in-flight agents from the stream
  • anyone waiting on me — the open gate queue
  • what did today cost — real metered tokens (or demo estimate)
  • what's reversible — which actions/gates can be undone
  • what did we learn — current Context Pack version

refusal + voice

honest by construction

Out-of-telemetry topics (ads, revenue forecast, valuation, runway, competitors) hit a refusal contract — it says it can't see that and offers what it can.

Voice is a Gemini Live WebSocket bridge (/ws/voice): audio in, audio out, same 5 tools, same refusals. No creds → text-only demo. Voice never says what text can't.

07The substrate that binds it

~1,400 lines of shared plumbing make the five systems one company.

One event stream

stream.py

An append-only, ordered log. Every surface — cockpit, gate queue, cost meter, witness — is a pure render of (stream, cursor). Live rows are designed to land in BigQuery as agent_events; demo rows are in-process. Same shape either way.

A2A contracts

a2a.py

Agent-to-agent handoffs as typed payloads — ContextPack, Dispatch, CreativeMaster, GateRequest, QuadrantResult. An in-process registry mirrors real A2A so wiring HTTP later is a transport swap.

Two stores

project.py / supastore.py

A file store by default; a dedicated Supabase project (saakshe, 7 RLS deny-default tables, service-role backend) when SAAKSHE_STORE=supabase. Drop-in replacement — survives restarts, supports multiple founders.

One FastAPI service

service/app.py

~15 endpoints behind one front door: /api/hero/run + approve (flywheel), /api/stream, /api/gates, /api/connect/* (ingest), /api/saakshe/ask, /ws/voice, agent-cards, and the cockpit at /.

Demo / live parity

config.py / models.py

The whole company runs creds-free via a ScriptedLlm replay, or live via real Gemini + Claude. "Live" is a flag, not a rewrite — the same orchestration (parallel, loop, gates, A2A) runs both ways.

Real token accounting

usage.py

Sums authoritative input/output tokens from ADK events per quadrant, so the witness's "what did today cost" is metered truth in live mode — not a guess.

09Honest caveats

  • Model pins are aspirational defaults. The IDs (gemini-3.1-pro-preview, gemini-3.5-flash) are env-overridable hackathon/preview pins, not guaranteed-GA names — real runs fall back to whatever Vertex serves. arivu deliberately keeps older 2.5 / Opus-4.1 pins.
  • Default mode is demo. The full flywheel runs creds-free on scripted replay; real side effects need live mode and an explicit allow-live-exec flag. A live run was blocked on Claude Vertex quota (~Jun 10).
  • A2A is in-process today. ADK's to_a2a() is blocked by the a2a-sdk 1.1.0 restructure, so agent-cards are served manually; the registry mirrors the real protocol shape.
  • "139 tests" is the current count (includes eval/quadrant suites); earlier notes cite ~122 core pytest.
