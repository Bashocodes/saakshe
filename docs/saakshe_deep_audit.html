SECTION II

Findings

The most interesting facts the audit surfaced — the clever, the structural, and the slightly self-contradictory.

FINDING № 01 — STRUCTURE AS LAW

kural is mute by schema, not by promise.

The delivery planner's output schema (kural/delivery.py) has no text field at all — it can pick a variant, a segment, a window, a rationale. It physically cannot author a word. The assembler then copies kalai's variant with the comment:

"text": formats.get(variant, "")  # kalai's words, VERBATIM

A prompt can be jailbroken. A missing field cannot.

FINDING № 02 — THE HARDCODED FLOOR

dry_run=True is written into the orchestrator twice.

At orchestrator.py:205 (arivu's executor) and :247 (kural's publish), dry-run isn't a default parameter — it's a literal. A real side effect requires a human tap and an explicit override. The whole company is, by construction, incapable of surprising you.

FINDING № 03 — THE GRADUATED PROSECUTOR

The verdict isn't voted on. It's attacked, then surgically repaired.

After Claude seals a verdict, a prosecutor (also Claude) attacks it and returns a faulted_reason_index. A reviser then repairs only that one reason — never a full reset — and the prosecutor re-attacks the strengthened version. The revision ledger is append-only: a surviving round records nothing, so no phantom repairs ever appear.

FINDING № 04 — MATH OUTRANKS THE MODEL

A contradiction zeroes groundedness. Permanently.

In manas's curator: if find_contradictions(claims): return 0.0. Contradiction detection is deterministic — subject match, polarity flip, numeric clash. No number of curation rounds, and no amount of model eloquence, can talk past it. The pack refuses to commit rather than fabricate.

FINDING № 05 — THE PEDANTIC REFUSER

The witness refuses on word boundaries, so "ad" can't hide in "already."

The out-of-telemetry list (ad, ads, advertising, valuation, runway, competitor…) is matched on word boundaries specifically so that "already," "roadmap," "headcount," "lead," and "deadline" don't trigger a false refusal. The witness holds zero static knowledge — its system prompt orders it to call a telemetry tool to answer anything at all.

FINDING № 06 — SIX FORBIDDEN PHRASES

Even if Claude's compliance gate were fooled, six sentinels hard-block the copy.

Belt and suspenders in kalai/tools/analyst.py: guaranteed, cure, miracle, competitor logo, #1 in the world, [unsafe]. The comment on "cure" reads "a health/medical claim a coffee brand can't make" — a fossil of Sundara Coffee Co., the fictional roastery the demos were first grounded on.

FINDING № 07 — THE 429-PROOF DEMO

Demo mode replays only the tokens. Everything else is real.

A ScriptedLlm slots in beneath the ADK so every Parallel, Loop, escalate, HITL gate and A2A dispatch executes for real — only token generation is replayed. The code's own justification: "the net that lets the whole flywheel demo creds-free and survive a 429 mid-demo." Byte-identical, run after run.

FINDING № 08 — THE BLAST-RADIUS CAP

No send over $500. No send twice. No send without consent.

kural's SendLedger marks a send before firing it, so retries can't double-send. Eligibility is checked in pure code before the tool runs: non-empty recipient, recorded consent, value under SEND_VALUE_CAP_USD = 500.0. Cold blasts are structurally impossible.

FINDING № 09 — THE CENSUS DISAGREES WITH ITSELF

The code counts 26 seats. The darshana plate counts 28.

common/config.py declares TOTAL_SEATS = 26 with kural at 5 seats — and carries the honest comment "Phase 4's delivery readers aren't built yet." But the git log shows commit 48acd35 did build those four delivery readers, and web/darshana.html already counts 28 seats with 8 Claude rings. The comment went stale faster than the company grew. Meanwhile the true model-bearing roster — counting every mantri sub-advisor and imbiber sub-reader — is north of 50. Three censuses, one company, and the audit's favorite bug that isn't a bug.

FINDING № 10 — FAN-OUT, FOLD VERBATIM

One pattern echoes through every faculty.

arivu's 5 mantris each fan into 3 sub-advisors; manas's 4 imbibers each fan into 4 sub-readers; kalai scores with a 4-judge fidelity panel; kural reads with 4 delivery readers. In every case a deterministic reducer lifts the primary's claim verbatim and attaches the rest as cited evidence — so the roll-up stays byte-identical to the pre-ensemble output, proven by keeping the original tests green.

FINDING № 11 — MONEY THAT APOLOGIZES

Every failure refunds itself, idempotently.

A flywheel run costs 20 credits; sign-up grants 100. Only one error in the universe counts as "out of credits" — Postgres P0001 with message INSUFFICIENT_CREDITS. Every other failure triggers an idempotent refund on a derived :refund key and a promise to the founder: temporary, not charged. Even a "no safe decision" verdict refunds the tap.

FINDING № 12 — THE FIRST CREATION

kalai's hands are proven by a 713 KB render checked into the repo.

docs/first_creation.png — a real Vertex Imagen 4.0 render from a brand-grounded AIKIZI prompt, 1024×1024. The model garbled the word "announcement" in the image, and the repo kept it anyway. The commit calls it "the true story — customer zero, AIKIZI, the first real creation." Honest artifacts over polished fakes.

SECTION VI

Curiosities

CURIOSITY № 01

The witness prices its own thoughts.

cost_today estimates spend at (input × 3 + output × 15) / 1,000,000 dollars — reading the same event stream the OTel spans describe. Telemetry isn't observability bolted on; it's the product surface the founder talks to.

CURIOSITY № 02

A budget that charges nothing, on purpose.

The chamber spec carries a TokenBudget class whose charge() is a no-op, annotated "Track B, step 9" — a promise to a future phase, checked in as scaffolding rather than left as a TODO.

CURIOSITY № 03

Claude lives in a different region than Gemini — so the code forked the client.

VertexClaude overrides the stock ADK client because Claude on Vertex is region-restricted while Gemini is global; CLAUDE_LOCATION rides independently of GOOGLE_CLOUD_LOCATION.

CURIOSITY № 04

The flywheel scales to exactly one machine.

deploy_cloudrun.sh pins --max-instances=1 --min-instances=1 because run state lives in an in-process dict. A whole AI company, deliberately capped at a single container — the honest size for a company run by one founder and two taps.

SECTION VII

The honest column

The project's most unusual feature is what it admits. The README's own words: "We'd rather show you exactly where the line is than blur it. Credibility is a feature." The audit's open items, in the same spirit:

Known and stated, not hidden

  • Production runs hybrid — real Gemini drives the flywheel; the 7 Claude seats run scripted replay while the Vertex Model Garden quota resubmission is pending.
  • The evalsets have never met a live model — all four faculties ship ADK evalsets with a 0.8 pass bar, creds-gated, explicitly "not yet run" rather than implied green.
  • The seat census drifts — config says 26, darshana says 28, and a config comment still claims the delivery readers "aren't built yet" two commits after they were built (Finding № 09).
  • The A2A SDK was blocked, not fought — a hand-built in-process registry is call-identical to a live A2A endpoint; wiring real transport changes one layer.
  • Run state is in-memory — a container restart forgets in-flight runs by design; the public demo self-heals back to the AIKIZI seed.
  • The first creation has a typo — and it's still in the repo, because a real artifact with a flaw beats a fake one without.
